## 💡 常见问题

### Q: 找不到Excel文件？
A: 检查训练是否成功完成，查看日志：
```bash
tail -f logs/training_$(date +%Y%m%d).log
```

### Q: 想要更多股票的预测？
A: 重新训练，增加股票数量：
```bash
python main.py --top-k-stocks 3000
```

### Q: 历史预测文件太多？
A: 可以手动清理旧文件：
```bash
find outputs/sina/*/predictions/ -name "*.xlsx" -mtime +7 -delete
```
